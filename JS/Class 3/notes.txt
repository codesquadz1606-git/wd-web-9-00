What is operators?
Operation b/w two or more operands is known as operators.

Type Of Operators:
i. Arthmetic : +,-,*,/,%,**
ii. Relational : <,>,<=,>=,!=,==,===(Only in JS)
    What is diffrence b/w == & ===?

iii. Logical : && || !
    && : Here all the condition must be true , if single condition is false then result will be false.
    Real Scenario : Login Page(username & Password dono correct honaaa chahiye.)
    I   II      R
    T   T       T

    || : Here , any single condition is true then result is true.
    Real Scenario  : Fingerprint Sensor
    I   II      R
    T   T       T
    T   F       T
    F   T       T

    ! : Reverse the answer.

iv. Unary : It always increae or  decrease the variable by 1.
    Increment & Decrement
    pre & post

v. Assignment : = , += , -= , *= , /= , %= , **=
vi. Teranary : Conditional Based
(condition) ? Statement if true : statement if false;
